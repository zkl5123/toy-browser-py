### 本批改动（扩展 document_process.py，不新建模块）
- `DocCommand.navigation_id` / `DocFrame.navigation_id`（默认 0，
  向后兼容）+ worker 持有 `_nav_id`（每 tab 每次导航 +1）+ 帧与
  payload 同步携带 + `drop_tab` 一并清理。
- `Worker.ipc_identity(tab_id)` → 四元组 dict
  （tab_id/navigation_id/document_version/frame_id）；既有
  `identity()` 三元组契约保留（向后兼容）。
- `COALESCABLE_COMMANDS = (resize, scroll)`（navigate/stop 不可合并）。
- `CommandCoalescer`：同 (tab_id, navigation_id, kind) 的可合并命令
  保留 seq 最大（最新几何），`merged` 计被合并掉的旧命令数；
  drain 按 seq 升序保因果。退化：无可合并命令时原样返回。
- `BackpressureGate(limit=256)`：在途达上限拒收（返回 False +
  计 dropped + `is_saturated`）。退化：低于上限恒 True。
- `CancelTracker`：取消须**被确认**（request → token，ack → 完成），
  `pending()` 未确认数（不静默）；`ack_tab(tab, nav)` 批量确认。
- `NavVersionGate`：**"旧任务不可覆盖新页"**判定层——同 tab 而
  navigation_id 更小的帧丢弃；同 navigation 内 frame_id 不推进也
  丢弃。`current(tab)` / `reset(tab)`（关标签清状态）。
- `UiHeartbeat`（心跳计数 + 最近时间戳）+ `TaskTrace` / `TraceSpan`
  （span 名 + tab/navigation 身份 + 起止时间 + ok + note；
  `max_spans=512` 有界丢最旧）。
- `gui.py` 接线：`__init__` 加 6 个组件字段（**局部 try/except
  import**，与 gui.py 既有风格一致，document_process 不可用时置
  None）；`_commit_navigation` 加心跳 + navigation_id 推进（每 tab
  每次 +1）+ trace span（navigate）+ 版本门控登记；新增
  `_r7_a02_describe()` 诊断串。

### "不冒充通过"口径（重要）
- 本批**只做可测决策层**：版本化身份 / 合并 / 背压 / 取消确认 /
  心跳计数 / trace 调用路径。
- **未验证**（留活 UI / GPU 批次，不宣称）：
  * worker 持 DocumentSession 执行**真实**解析/样式/布局/绘制
    （现有 worker 是紧凑身份计数，非真实文档工作）；
  * 真实多核加速（需真实 spawn + 活显示性能实测）；
  * 真实墙钟响应延迟（P95 ≤ 100ms，需 Tk 事件循环实测）；
  * 连续 buffer / 受控共享内存帧传输（现为 pickle 紧凑对象）；
  * 子进程真实 spawn 回收（本次未跑真实 spawn 回归）。
- `UiHeartbeat` 只记"UI 主线程被真实调用次数"，**不**测真实响应
  延迟；`TaskTrace` 只记调用路径与阶段耗时，**不**宣称多核加速。
