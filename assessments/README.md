通用架构、贡献指南、变更记录及长期路线图放在 [docs](../docs/PROJECT_STRUCTURE.md)，回归测试用例在 `tests/`，性能工具在 `tools/`。所有文档和源码位置均以 [项目结构](../docs/PROJECT_STRUCTURE.md) 为准。

从项目根目录执行复测脚本，例如 `python assessments/20261016-round5/toy_js_runner.py`。多数脚本会覆盖所在轮次的结果文件；再次复测应复制到新的轮次目录运行，保留历史证据。外部对照浏览器的依赖与环境要求见各轮报告。
