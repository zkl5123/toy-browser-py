# 第七轮评估方法与标准基线

日期：2026-10-18。产品快照：`2d1bdd31c982fe6637be30da393f47f4170e2750`。报告面向“真实可运行的 Python 浏览器内核”目标，不以教学项目标准降低要求。

## 1. 如何理解“完整评估”

本轮按模块、入口、调用链、关键标准语义、安全边界与可复现行为进行系统审计，不宣称逐行形式化验证、完整标准认证或覆盖所有网站。源码清单覆盖 `toy_browser/` 的 91 个 Python 文件 / 44,989 行，`tests/` 的 95 个文件 / 33,334 行，`tools/` 的 6 个文件 / 798 行。清单、行数和 SHA-256 见 [source-inventory.json](../source-inventory.json)。行数包括注释和空行，不代表有效功能量。

评估关注三种常被混淆的完成程度：

1. **组件存在**：有类、方法、返回值或独立单元测试。
2. **主链集成**：真实导航、脚本、输入、绘制路径实际调用，并传递相同上下文。
3. **标准行为成立**：正例、反例、跨源、重定向、生命周期和最终像素/用户动作均满足断言。

只有第三层可以作为相关能力的验收。进程成功 spawn 不等于页面在工作进程渲染；CPU 像素上传显存不等于 GPU 执行光栅化；导出可访问性树不等于操作系统读屏可用。

## 3. 规范与验收来源

以下为 2026-10-18 检索/阅读的规范入口。Living Standard 会演进，后续应固定具体提交、抓取日期及用例版本；本轮未镜像整套规范。

| 领域 | 权威入口 | 本项目应验证的契约 |
|---|---|---|
| HTML | [HTML parsing](https://html.spec.whatwg.org/multipage/parsing.html#parsing) | tokenizer 与 tree construction、插入模式、隐式元素、错误恢复、表格 foster parenting、RCDATA |
| DOM 与事件 | [DOM Standard](https://dom.spec.whatwg.org/) | 节点身份、插入/删除、事件路径与监听器语义、取消默认动作 |
| 脚本与事件循环 | [HTML event loops](https://html.spec.whatwg.org/multipage/webappapis.html#event-loops) | task/microtask 检查点、timer、rAF、导航时上下文销毁 |
| ECMAScript | [ECMA-262](https://tc39.es/ecma262/) | 值类型、严格相等、UTF-16 字符串、转换、数组排序、属性顺序、Promise jobs |
| 级联 | [CSS Cascade](https://www.w3.org/TR/css-cascade-5/) | origin/importance/layer、specificity 元组、源码顺序、继承 |
| 选择器 | [Selectors](https://www.w3.org/TR/selectors-4/) | 结构和状态选择器、匹配上下文、缓存失效 |
| 布局 | [CSS Flexbox](https://www.w3.org/TR/css-flexbox-1/)、[CSS Grid](https://www.w3.org/TR/css-grid-1/) | 格式化上下文、intrinsic sizing、分配算法、跨轨道与 gap |
| 网络与跨源 | [Fetch](https://fetch.spec.whatwg.org/) | request mode/destination/credentials、CORS 预检与响应过滤、跨源重定向、请求头限制 |
| URL | [URL Standard](https://url.spec.whatwg.org/) | URL 解析、相对解析、origin 序列化；base URL 不等于文档 origin |
| 安全策略 | [CSP](https://www.w3.org/TR/CSP3/) | 请求前检查、重定向检查、脚本执行检查、connect-src、策略不随加载开关消失 |
| 可访问性 | [HTML AAM](https://www.w3.org/TR/html-aam-1.0/) | 角色/名称/状态映射到平台辅助功能 API，不仅是 Python 字典 |
| 外部测试 | [WPT 测试分类](https://web-platform-tests.org/writing-tests)、[Test262](https://tc39.es/test262/) | testharness/reftest/crashtest/manual 分类；JS 语言单独验收 |

DOM/CSS/URL/CSP/AAM 链接为后续实施的官方规范入口；本轮直接检索并读取了 HTML parsing、Fetch、ECMA-262、WPT 测试分类。不声称逐章核验所有链接内容。

### 安全规则不能简单过度收紧

- CORS 限制脚本对跨源响应的读取；不能粗暴规定所有跨源经典脚本、图片和样式必须有 ACAO，否则会破坏正常网页。
- `no-cors` 不是“关闭安全检查”，其响应通常对脚本表现为 opaque。
- `document base URL` 用于相对地址解析，安全 origin 来自文档实际响应，不可被 `<base>` 改写。
- 子进程用于故障/性能隔离，不天然具有操作系统沙箱权限限制；Python 内存限额和 JS 指令预算也不能替代沙箱。

## 4. 本轮运行与口径

### 环境

- Windows 11，具体版本与执行时间见 [environment.json](../environment.json)。
- 默认受管 Python 路径包含 `3.13.12`，实际 `sys.version` 为 **3.13.14**；没有 tkinter/wgpu/PIL/playwright。
- 为补足 Tk/wgpu 能力，使用机器上已有项目 Python **3.11.9** 执行补充全量回归；没有安装新依赖，版本见 [native-environment.json](../native-environment.json)。
- 两种 Python 的通过数、耗时和失败必须分开；不能据此直接归因为代码回退。

### 可复现命令

从项目根目录执行；请将 Python/Node 路径替换为本机实际受控环境，不要仅根据目录名判断版本。

```text
<managed-python> assessments/20261018-round7/run_assessment.py --full --legacy --profile
<managed-python> assessments/20261018-round7/semantic_probe.py
<managed-python> assessments/20261018-round7/compare_results.py
<managed-python> assessments/20261018-round7/render_probe.py
<managed-python> assessments/20261018-round7/security_probe.py
<full-python> test.py --full --report
```

`run_assessment.py` 只在第七轮写输出、读取第五轮夹具，不改写历史证据。它对子进程设置有界超时，并保存独立 stdout/stderr/退出码。已有测试自身可能在其设计路径生成临时文件，因此执行前后仍需检查 Git 状态。

### 比较规则

- JS 历史样本：分别统计日志原始相等、去首尾空白相等、错误类别一致；不能隐藏错误文本不同。
- 新增 JS：比较标准字符串化日志与是否异常。少数不支持项会暴露 Python 对象表示，仅作当前实现证据，不是标准输出。
- 布局：同为 800×600，比较 border-box 的 x/y/w/h，误差不超过 1 CSS px；48 个盒子通过不覆盖文字 shaping、paint order 或实际点击目标。
- 渲染/GPU：捕获上传字节和资源键可证明逻辑问题，不等于真实 GPU shader 或 surface 呈现验证。主评估阶段另行独立复跑渲染/安全两个探针，退出码均为0，结果口径一致；日志见 `render-probe-validation-*.txt` 和 `security-probe-validation-*.txt`。退出0表示探针执行完毕，不能把探针观察到的产品缺陷抹去。
- 性能：每规模 3 个样本，保留原始值与中位数。分段基准走历史 CPU API，且审计期间有其他进程活动；不用于严格跨轮排名或宣传加速倍数。
- 所有定向探针有选择偏差，是为了暴露缺陷，不可计算为“浏览器兼容率”。渲染32项还混合标准语义、工程契约和组件正向控制：例如void-siblings仅验证当前解析器片段形态，不能作为完整document隐式树符合标准的证据；surface/family字段是内部工程契约，不是WPT原题。

## 5. 本轮未覆盖的风险与补测清单

1. 当轮 Chromium + Firefox + WebKit 三内核对照、全量 WPT 和 Test262。四张当前PNG已生成并记录哈希，但当前会话图像读取能力不可用，未完成评估者视觉判读；可供用户或下一轮独立视觉评审复核。
2. 真实 IME 候选框、触屏、HiDPI 跨屏、屏幕阅读器、系统剪贴板权限与完整文件选择器。
3. 网站登录、支付、真实账户、隐私数据；本轮禁止使用这些敏感流程作为测试。
4. 恶意页面的真实系统逃逸利用、网络攻击、无界解压/图片/字体压力；只进行无害属性探测和有界本地夹具验证。
5. HTTP/2/3、Service Worker、WebRTC、完整音视频/DRM、WebGL/WebGPU 网页 API。
6. 持续数小时稳定性、崩溃恢复、内存泄漏、网络重连和 GPU 设备丢失的完整生命周期。

这些项目应纳入后续产品门禁，不能在本轮写成“均已支持”或“均已失败”。
