# 第七轮逐项改进实施方案

基线：2026-10-18 / `2d1bdd3`。本文件是实施计划，不是实施完成记录。**本轮不修改产品代码。** 工作项采用 R7 前缀，避免与旧 G/C/B/P 系列混淆；旧编号完成不自动代表本轮验收通过。

## 1. 总体顺序与依赖

```text
R7-Q01 测试可信度 ───────────────────────────────┐
R7-S01 JS宿主边界 → R7-S02 请求策略 → S03 Cookie │
R7-S04 有界IO/解压 ──────────────────────────────┤
R7-A01 文档/导航唯一主链 → A02 真实文档工作进程 ─┤
R7-J01 JS值语义 → J02 调度 → J03 Web API ────────┤
R7-H01 HTML → C01 CSS正确性 → C02布局 → T01字体 ┤
A01 + C02 → U01命中/状态 → U02编辑/IME → U03A11y │
Q01 + A01 + C01/C02 → P01基准/热点 → P02 GPU ────┤
全部相关门禁 + Q02外部测试 → Q03有限场景发布 ────┘
```

不要等完整 JS 引擎或 GPU 完成才修安全；也不要一边继续扩展大量新 API，一边保留多个互不一致的页面主链。建议每个批次做到“产品默认入口接通 + 反例 + 端到端 + 文档同步”后再扩范围。

## 2. 批次 0：可信验收与安全收口（P0）

### R7-Q01：让红灯真的导致失败

**落点**：`tests/run.py`，`tests/test_p34_r4.py`、`test_p34_r5.py`、`test_p34_r6.py`、`test_document_process_spawn.py`、`test_tk_keyboard_binding.py` 及其他依赖环境的用例。

1. 发现阶段统计 discovered_modules / expected_tests；模块 import 失败记 ERROR，并返回非零，不能缩小分母后继续成功。
2. 引入 PASS/FAIL/ERROR/SKIP/XFAIL/XPASS/TIMEOUT 明确结果，不再把无 Tk/无 GPU 时的提前 return 计为功能通过。
3. `--only` 未知模块、空选择集、Tcl 子进程没有合法 summary 均失败；子进程有 timeout，保存 stderr，而非无条件吞掉。
4. 测试 `_check/_ok` 不能只打印 FAIL；改为抛断言或把内部失败数返回 runner。benchmark 若只信息性展示，输出 WARN/INFO，不使用 PASS/FAIL 误导；硬性能门禁在隔离基准任务中执行。
5. 删除 `assert condition or True`、`len(...) >= 0` 等恒真断言；spawn 测试需要证明 payload 包含真实 DOM/layout/frame，且默认 GUI 动作实际产生工作请求。
6. 输出 machine-readable JSON/JUnit，并存 test ID、耗时、环境/后端、skip 原因和异常栈；把功能正确性与性能回归分开。

**验收**：注入一项 import 失败、无效 --only、内部检查失败、GPU 缺失、Tcl 超时，分别得到 ERROR/FAIL/SKIP/TIMEOUT 的正确退出码与稳定分母。本轮 1914/1914 不能作为旧断言不变的理由：它包含内部 FAIL 未传播问题。

**交付**：测试编排变更、状态结构、故障注入测试、两种运行时报告；不必在这一步改产品语义。

### R7-S01：关闭 JS 到 Python 的任意对象访问（P0）

**证据**：页面可读 `location._host.doc_url`、`localStorage.__class__.__name__`、`fetch.__self__._js_step_budget`；详见安全审计 S01。

**落点**：`scripting/js.py` 的 member read/write/call；`scripting/web_api.py`；DOM/Response/Promise 包装对象。

1. 先提供明确的远程脚本禁用开关/可信页面模式；安全边界完成前不得默认把任意网络页面当可信代码运行。
2. 定义 JSValue/JSObject/HostObjectDescriptor，不允许解释器任意 `getattr/setattr`；dot、bracket、optional chain、方法抽取、call fallback 必须共用同一访问器。
3. Web API 只导出标准可见属性和明确 callable handle，宿主状态放在 JS 不可见的映射；不能只屏蔽 `__`，普通 `_host` 同样危险。
4. 异常转为标准 JS 异常，不把 Python 对象 repr/函数地址作为页面结果。
5. 结合 A02 增加独立执行进程和有限 IPC；操作系统沙箱/权限收敛单独验收，不能把 spawn 写成安全沙箱。

**验收**：本轮三条无害探针以及所有 DOM/网络/观察器包装对象均不能访问宿主私有字段；合法 Web API 仍可用；异常、预算和导航取消有效。不要用真实文件、凭据或破坏性操作验证。

### R7-S02：一个 RequestContext 贯穿所有请求（P0）

**落点**：`network/net.py` 的 HttpClient/FetchTransport/load_subresources；`browser.py`、`gui.py`；`js.py` fetch/XHR。

1. RequestContext 明确 document_origin、base_url、site_for_cookies、destination、mode、credentials、method/body/headers、DocumentPolicy、redirect chain、deadline、navigation_generation。
2. 文档响应后无条件构建策略，与 `load_subresources` 开关解耦；origin 不得由 `<base>` 改写。
3. 发送前检查 CSP/connect-src/目标 scheme/混合内容政策；逐跳重定向重新评估，跨源敏感头按规范剥离。
4. 按资源类型区分 navigate/classic script/module/img/style/fetch/XHR；同源无需 ACAO，classic 默认 no-cors 与 module/crossorigin 必须区分。
5. CORS 预检、Origin、ACAO/ACAC、credentials、opaque response 和禁止响应头统一实现；不支持模式明确拒绝，不偷换成放行。
6. CSP 区分“无指令”与“空指令”；重复指令保留首次；on*、字符串脚本等执行入口共用策略；被禁止请求不得先发包再丢响应。

**验收**：双回环来源矩阵 + 每跳重定向；connect-src/img-src none 服务器计数为零；跨源 fetch/XHR 无许可不可读；同源 script self 不因缺 ACAO 被误拦；关闭资源下载不解除 inline CSP。全部同时走 CLI 与 GUI 默认入口。

### R7-S03：Cookie、缓存和存储上下文（P0/P1）

**依赖**：S02；**落点**：`cookie_store.py`、`net.py` CacheStore/headers、`web_api.py` Storage。

1. Cookie 加 host_only、creation_time；Domain 公共后缀验证、默认 Path、Secure/HttpOnly/前缀/SameSite 规则；维护受控 PSL 数据及更新策略。
2. 所有发送和重定向使用真实 site-for-cookies/credentials，不使用缺省“同站顶层 GET”。
3. 响应头用多值结构，保留全部 Set-Cookie；GET/POST/redirect 统一入库。
4. 缓存校验 Vary、no-store/no-cache、授权响应、304 头合并；缓存记录不得串 origin/凭据策略。
5. StorageService 在宿主侧按 profile+origin（local）或 tab+origin（session）管理；opaque origin 策略明确，同源导航保留、跨源隔离。
6. 配额增量计算、失败原子化、清理和驱逐；通过 S01 的封装禁止直接触达内部 dict。

**验收**：host-only 不去子域、Path 正反例、重复 Set-Cookie 均保留、跨站 Strict 不发送、POST Cookie 入库；同源 Storage 保留但不同端口隔离；304 后安全响应头仍正确。缓存问题当前主要静态风险，先补最小复现再修。

### R7-S04：分配之前限制网络与页面资源（P0）

**落点**：`net.py` GET/POST/解压/连接池；`common/mem_guard.py`；JS/图像/字体入口。

1. GET/POST 共用分块 reader，限制原始字节、解压字节、每请求及每页面总预算。
2. gzip 用有界增量解压；实例 max_response_bytes 贯穿所有路径；不能先 read()/decompress 完再检查。
3. deadline、取消与连接关闭放进共同 finally；超限连接不归还可复用池。
4. 页面 DOM 数量/深度、源码字节、图像像素、字体表/组件、任务队列和 IPC 队列设独立限额。
5. worker 超时后由父进程有界终止并展示错误页，允许关闭/新导航；日志只记录有限摘要。

**验收**：128 字节限额拒绝 129 字节 raw/gzip decoded/POST；测试 reader 断言有界 read 参数；以几 KiB 样本验证即可，不运行内存耗尽攻击。取消后连接与任务计数收敛。

## 3. 批次 1：一个真实页面主链（P0/P1）

### R7-A01：收敛 DocumentSession 与 NavigationController

**落点**：`app/browser.py`、`app/gui.py`、`document_state_full.py`、`document_renderer.py`、`navigation.py`、`history_entry.py`、`b_series_wiring.py`。

1. 画清当前 API/CLI/GUI 各自 parse→Host→policy→style→layout→display-list→frame 路径，标出重复实现。
2. 指定唯一 DocumentSession 所有者：DOM、Host、policy、资源、stable node IDs、版本、scheduler、client；旧 API 作为适配器，不再自行复制管线。
3. 地址栏/链接/表单/启动参数/JS location/刷新/历史全部提交 NavigationRequest；明确 assign/replace/reload/hash 的历史差异。
4. 导航链跨 hop 共享 seen、session/client、最终 URL 与预算；消费脚本同步、timer、事件回调产生的导航，不仅首次脚本后检查一次。
5. commit 按 generation 原子替换文档状态；about/error 页面也清理旧 DOM/Host/display-list/hit tree/任务，不仅换 bitmap。
6. DocumentVersion 只在真实阶段变化时更新，旧帧、旧网络完成和旧 callback 不可回写新页面。

**验收**：同一 fixture 的 CLI/GUI DOM 指纹、策略请求、事件、导航最终 URL 一致；replace 历史项不增；A→B→A 循环有界；about/error 后旧元素不可点击、旧脚本不执行。原 B01/B03/B05 回归保持，通过新增缺口案例才算主链完成。

### R7-A02：把实际页面工作移出 UI 线程

**证据**：现有 worker 存在且 spawn，但默认导航仍同步，worker handle 主要返回 URL/版本状态；不能据名称宣称已多核渲染。

1. 先在默认导航/resize/scroll 入口加入 UI 心跳和 task trace，确认真正调用路径。
2. worker 持有 DocumentSession，执行网络等待/解析/JS/样式/布局/绘制；UI 只提交命令、处理输入、呈现结果。
3. 定义版本化 IPC：tab_id/navigation_id/document_version/frame_id，命令合并、背压、取消确认、进程退出回收。
4. 帧用连续 buffer 或受控共享内存，不序列化整棵 Python 对象图；父进程不接触 worker 内部 Host。
5. 慢页与坏脚本不影响其他标签；关闭窗口先停止任务/回收子进程，再销毁 Tk root。
6. 在工作进程未完全接通前保留显式单进程调试模式，但默认模式的性能/安全声明必须真实。

**建议验收目标（未实测成绩）**：回环 250ms 延迟与有界重排期间 UI 心跳持续；输入响应 P95≤100ms；旧任务不可覆盖新页；关闭后无遗留子进程。spawn 实测必须断言 worker 执行真实解析/渲染，而不只是回包。

## 4. 批次 2：语言和 Web API 基础（P1）

### R7-J01：先修语言值语义，再扩语法糖

**证据**：新增 24 项纯 JS 与当轮 Node/V8 比较只有 11 项一致；详见 [semantic-probes.json](../semantic-probes.json)。

**落点**：`scripting/js.py` lexer/parser/interpreter/builtins。

1. 为 Undefined、Null、Boolean、Number、String、Symbol、Object 建明确类型语义，避免 Python bool 是 int 子类导致 `true===1`。
2. 统一 ToPrimitive/ToBoolean/ToNumber/ToString、严格/宽松相等、SameValue/SameValueZero。
3. String 的可观察索引和长度采用 UTF-16 code units；迭代码点与字素不能混为一层。
4. 补可调用 Number/Boolean、全局 parseInt/parseFloat；默认 Array.sort 按字符串 UTF-16 字典序而非数字排序。
5. 属性枚举使用整数索引先序规则；补 `in` 与数组空洞语义。
6. 对已经支持的 const/let/closure/try/async 等补边界，不用大范围“ES 中级”描述替代清单。

**验收**：24 项全部按独立标准预期通过，再扩小批 Test262；每项记录支持/明确不支持。Node 只作为纯语言第二实现，不作为 DOM/网络标准。

### R7-J02：事件循环和脚本生命周期

1. 一个 scheduler 管任务、微任务、timer deadline、rAF、渲染机会；每个任务后微任务检查点。
2. 删除“sync→timers→microtasks 是 V8 规则”的错误注释和基于此的测试期待。
3. parser-blocking 脚本与增量 DOM 解析协调；defer、async、module 明确分类；未实现 module loader 时不把 module 当普通 classic 执行。
4. 实现 document.readyState、DOMContentLoaded/load 及阻塞资源条件。
5. 导航 generation 取消旧任务；回调异常只终止当前任务，进入统一 diagnostics。

**验收**：sync→Promise→timer、两个 timer 中间的微任务、脚本间微任务、rAF、defer/load 次序；关闭标签没有残留 timer。不要靠一次 flush 所有队列模拟真实时间。

### R7-J03：Fetch/XHR/Response、事件与错误诊断

1. 修 Response.text/json/arrayBuffer executor resolve/reject 参数顺序；无效 JSON 拒绝 SyntaxError。
2. XHR.method/body/headers 真实下传；404 传输成功触发 load，网络失败才 error；fetch 404 fulfilled 且 ok=false。
3. 实现 bodyUsed/一次性读取、响应头过滤、最终 URL 与 AbortSignal；依赖 S02 安全上下文。
4. 捕获/冒泡/once/passive/stopPropagation/preventDefault 与默认动作明确分层，不以监听器列表替代 DOM event path。
5. B03 runtime throw 与 parse error 统一结构化记录，避免只 log 导致诊断显示零错误。

**验收**：回环服务器核对 method/body、文本/JSON正常读取、跨源不可读、取消、事件次序、错误分类；同一坏脚本不得阻断后续好脚本。

## 5. 批次 3：解析、样式、布局与文字（P1）

### R7-H01：HTML 先构建正确 DOM

**落点**：`document/html_pkg/tokenize.py`、`build.py`、节点模型。

1. 规范化 tokenizer 状态，补 RCDATA/rawtext/script data/字符引用，不用通用文本规则处理 textarea/title/script。
2. 实现必要 insertion modes 和隐式 html/head/body/tbody；正确处理 p/li 自闭合、表格 foster parenting、格式化元素恢复。
3. 区分完整 document 与 fragment parsing；保留 quirks mode/doctype/namespace 基础。
4. parser 与 J02 的脚本暂停/恢复接口一并设计，避免以后再重写。

**验收**：树结构 fixture 与标准期望比较，不只截图；畸形 HTML、textarea 字符引用、表格混合文本、fragment、脚本前后 DOM 可见性。

### R7-C01：修 CSS cascade 和选择器缓存（优先于新 CSS 特性）

**落点**：`style/css.py` parse_selector/specificity/apply/_candidate_rules_cache。

1. specificity 用 (ID, class/attribute/pseudo-class, type/pseudo-element) 元组字典序；不得把各项简单相加。
2. 缓存“候选规则筛选”与“最终匹配”分离；key 包含实际需要的 id/结构/状态上下文或对不安全选择器禁缓存。
3. DOM 重排、属性/class/id变化、hover/focus、祖先状态影响时精确失效；正确性优先于命中率。
4. 逐步补 origin/importance/source order、伪类函数、继承和 custom property resolution；`@supports` 应能力感知，不得总返回支持。

**验收**：#x 胜过 .a.b；相同 tag/class 的第二兄弟不继承 first-child/id 匹配；动态调整顺序和 class 后重新匹配；缓存开/关结果完全一致。

### R7-C02：格式化上下文与布局算法

**落点**：`layout/layout.py`、`rendering/inline_layout.py`，绘制和命中树关联。

1. 本轮先修 Grid row-gap 重复累计和 table colspan 宽度；每个缺陷增加最小几何断言与无文字 reftest。
2. block/inline/anonymous box 与 line box 明确；文本节点嵌套样式不丢连续行内上下文。
3. Flex 按 basis→grow/shrink→min/max→freeze→align 分步，补 wrap/intrinsic/min-width:auto；Grid 按 track sizing/spanning/gap 分步。
4. table 列约束、colspan/rowspan、border-collapse、caption 和 baseline 形成统一求解。
5. stacking context/clip/transform/scroll 坐标统一，绘制顺序与 hit-test 同源。
6. dirty subtree 优化必须与整树参考渲染差分，无法证明依赖安全时回退全量。

**验收**：保留旧 17 页面/48 盒子全部通过，加本轮失败项及边界；几何、像素、点击目标三种结果都要检查。

### R7-T01：真实字体、shaping 与断行

**落点**：`typography/font.py`、`text.py`、`ttf_font.py`、`rasterize.py`；layout 与 DisplayCommand 字体字段。

1. 不重复实现已存在的 TTF/TTC 解析和 coverage mask；先验证它们从 CSS 到 layout/paint 的实际使用链。
2. 字体缓存键包括具体 face、glyph ID、size、weight/style、DPI、render mode，测量与绘制必须使用同一 face/advance。
3. 建 shaping/run 接口，处理 combining marks、连字、RTL/Bidi、字体 fallback、emoji/缺字；自研可限定公开子集，但不能等同完整排版。
4. 换行遵循 Unicode 断行和 white-space 语义；以 grapheme/cluster 边界维护选择和光标。
5. 若坚持纯标准库，明确长期成本；若允许可选 native backend，可在接口后接成熟 shaping/raster 库，同时保留自研参考路径。此为用户决策点，不在评估中擅自引依赖。

**验收**：中文/拉丁混排、字体变化、16/17px、粗斜体、组合字符、RTL、行内基线和选区；视觉 reftest 固定字体文件/hash/DPR，不能以白背景全图低差异率掩盖文字错误。

## 6. 批次 4：GUI 用户任务与可访问性（P1）

### R7-U01：节点身份、页面切换与关闭

1. `gui.py` hit_test_at 和 _node_index_to_dom 不再用两套遍历计数，改 stable node_id→DOM 映射；文本节点也必须有明确命中归属。
2. about/error/history/新 URL 都经 A01 原子替换状态；当前 bitmap、display-list、DOM、Host、hit tree 永远属于同一文档版本。
3. resize/scroll/zoom/DPR 使用统一坐标变换，命中测试应用逆变换；滚动不重跑初始脚本。
4. WM_DELETE_WINDOW 在有界 shutdown 后 destroy root；异常路径也不能留下窗口与孤儿 worker。

**验收**：文本在按钮前时仍点中正确按钮；加载有色页后 about:blank 画面与交互都清空；关闭窗口退出事件循环；150%/200% 缩放点击位置正确。

### R7-U02：真正接上编辑层和 IME

1. 先确认 EditorOverlayController 只是状态模型，不能当作已经创建原生编辑控件。
2. 实际创建 Tk Entry/Text 或其他允许的原生输入桥，按控件几何定位，绑定 focus/composition/input/selection。
3. 浏览器模型中的 value/selection 与原生控件双向同步；blur/submit 写回，密码/只读/disabled/textarea/select 分别处理。
4. 窗口滚动、缩放和重排时更新覆盖位置；候选框位置正确；禁止提交过程中销毁编辑态。
5. ctrl+a/c/x/v、undo/redo、Home/End、方向键及标签切换完整测试；未接系统剪贴板时明确限制。

**验收**：真实中文输入法输入/选词/取消/提交，复制粘贴、密码遮罩、退格、选区替换、多行编辑；自动状态测试之外必须保留人工任务记录。

### R7-U03：无障碍与浏览器外壳

1. 将现有 accessibility tree 视为内部基础，映射到 Windows UI Automation 等平台桥，维护 name/role/value/state/focus 事件。

**验收**：仅键盘完成打开本地页→填表→提交→后退→关闭；读屏器能读控件名称/值和状态变化；失败任务不得用静态树导出替代通过。

## 7. 批次 5：性能与 GPU（P2，先正确性）

### R7-P01：先测真实默认主链再优化

1. 分别计 parse/style/layout/emit/raster/upload/present/encode；区分 CPU Bitmap、CPUImage、GPU 上传路径，不能混报。
2. 每种负载预热后至少 10 样本，记录中位/P95、峰值内存、长任务；隔离并发审计负载。
3. 本轮 5000 节点旧 CPU API 中 layout+emit 占主要成本；优先减少重复 style 查找、遍历、对象创建与不必要全树重建。
4. dirty invalidation 不得复用错误 CSS 结果；优化前后须像素/几何/事件一致。
5. 视口 tile 与滚动复用替代全页巨幅位图；PNG 导出不计入常规交互帧时间。

**建议门禁**：相同环境相同 fixture P95 不退化超过约定阈值（建议 10%，先建立稳定分布）；60Hz 场景 16.7ms 只是目标，不能在未测主链时宣称达标。

### R7-P02：把“GPU上传验证”发展为真实GPU绘制

**现状**：`gpu.py:794` CPU rasterize→`:812` 全帧上传；P05/P06 在帧已生成后做缓存准备；present 只是有帧返回真。

1. **先修资源正确性**：图片 key 用 ResourceID+内容版本（或稳定内容哈希+尺寸/格式），不能只尺寸+像素数量；alpha 和更新失效正确。
2. atlas 写入实际 glyph coverage，不能上传全零；使用 T01 的真实 face/glyph/size/DPI，去掉 ord(ch)&0x7F 和硬编码 family。
3. DisplayList 扩充资源引用、clip、transform、opacity、font run，避免 GPU 从缺字段结构猜测字体。
4. 实现矩形/图像/字形的真实 render pass/shader；CPU 作为独立 oracle，不允许 GPU render 先把整帧在 CPU 画完。
5. 连接原生 surface/present/swapchain、resize/device-lost，明确 GUI 后端边界；普通帧不读回，截图才读回。
6. 透明合成、圆角、阴影和滤镜在基础正确后逐项迁移；没有可用设备时可解释地 CPU 回退。

**验收**：同尺寸红/蓝图片生成不同纹理；atlas 有非零 alpha且中文不等同ASCII替身；GPU实际绘制单独通路像素对照通过；frame trace证明CPU不做整帧raster；surface更新可见；记录GPU时间/上传字节/帧时间，证明具体负载收益。CPU图上传再读回一致只算传输正确，不算加速。

## 8. 批次 6：标准测试、发布与长期能力（P1/P2）

### R7-Q02：接入外部测试，不只增加自有测试数量

### R7-Q03：分级发布，不以功能列表宣称通用浏览器
